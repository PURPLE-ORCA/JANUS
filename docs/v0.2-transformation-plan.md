## Stage 2: Data Layer ✅

### TypeScript Types Updated

**New Interfaces:**

- `Company` — Company profiles with sector and verification
- `ProfileEducation` — Education entries with institution, degree, field
- `ProfileExperience` — Work history with company, title, description
- `ProfileLanguage` — Language proficiencies (basic → native)
- `OfferScreenerQuestion` — Pre-screening questions with types
- `ApplicationNote` — Recruiter notes with author

**Extended Interfaces:**

- `User` — Added avatar_path, profile relation
- `Profile` — Added 12 fields: city, country, DOB, nationality, years_of_experience, expected_salary, availability, education_level, has_driving_license, portfolio_url, and nested relations
- `Offer` — Added 10 fields: company_id, work_mode, experience_level, education_required, languages_required, benefits, positions_count, views_count, is_urgent, company relation
- `Application` — Added screener_responses, rejection_reason, interview_at, notes relation

**New Enums:**

- `CompanySector` — tech, finance, healthcare, retail, services, education, other
- `Availability` — immediate, 1_week, 1_month, negotiable
- `EducationLevel` — bac, bac+2, bac+3, bac+5, phd (Morocco-specific)
- `ExperienceLevel` — junior, mid, senior, lead
- `WorkMode` — onsite, remote, hybrid
- `LanguageProficiency` — basic, intermediate, fluent, native
- `QuestionType` — yes_no, text, number, select

### Mock JSON Data Updated

| File                | Records  | Updates                                                  |
| ------------------- | -------- | -------------------------------------------------------- |
| `companies.json`    | 10       | New file with Moroccan companies across 7 sectors        |
| `profiles.json`     | Extended | Added education[], experience[], languages[] arrays      |
| `offers.json`       | Extended | Added company_id, work_mode, experience_level, etc.      |
| `applications.json` | Extended | Added screener_responses, interview_at, rejection_reason |

### Hooks Updated (`use-mock-data.ts`)

**New Hooks:**

- `useCompanies()` — List all companies
- `useCompany(id)` — Single company by ID
- `useVerifiedCompanies()` — Only verified companies

**Extended Hooks:**

- `useOffers()` — Added companyId, sector, workMode, experienceLevel, isUrgent filters, populates company relation
- `useAdminStats()` — Added totalCompanies, urgentOffers, interviewsScheduled
- `useCandidateStats()` — Added interviews, offered counts
